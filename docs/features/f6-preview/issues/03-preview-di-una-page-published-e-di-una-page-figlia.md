# 03: Preview di una Page Published e di una Page figlia

**Issue:** [#72](https://github.com/mikeleg/kets-cmsm/issues/72)

**What to build:** Il Client controlla una modifica non salvata a una Page Published, e capisce perché una Page figlia non è visibile.

**Blocked by:** F6/01 Preview di una Page in Draft (#65); F3/04 Albero delle Page (#59)

**Status:** ready-for-agent

- [ ] La Preview di una Page Published mostra la modifica non salvata. I visitatori vedono ancora la versione salvata.
- [ ] La Preview di una Page figlia di una Page in Draft funziona e porta un avviso: i visitatori non la vedono perché la Page padre è in Draft.
- [ ] Test sull'API per i due casi.

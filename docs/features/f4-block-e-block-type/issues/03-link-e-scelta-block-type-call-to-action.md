# 03: Link e Scelta, Block type Call to action

**Issue:** [#61](https://github.com/mikeleg/kets-cmsm/issues/61)

**What to build:** Il Client aggiunge una Call to action con un link a una Page del Site o a un sito esterno.

**Blocked by:** F4/01 Registro dei Block type e Testo formattato (#56); F3/03 Page nuova in Draft e pubblicazione (#55)

**Status:** ready-for-agent

- [ ] Il Field Link punta a una Page del Site o a un URL esterno e ha un'etichetta.
- [ ] Il Field Scelta offre un'opzione da un elenco fisso.
- [ ] Il Block type Call to action ha titolo, testo e link.
- [ ] L'etichetta del Link è traducibile. La destinazione del Link e la Scelta sono comuni a tutte le Language (ADR 0004).
- [ ] L'API pubblica restituisce l'URL attuale della Page collegata.
- [ ] Test sull'API per Link interno, Link esterno, Scelta e Field obbligatori.
